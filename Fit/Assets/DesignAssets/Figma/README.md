## 📱 设计素材说明

本目录包含从 Figma 设计稿下载的界面设计截图，作为开发参考和设计规范。

## 📁 文件列表

### 1. workout-screen-design.png
- **来源**: https://www.figma.com/design/V65DyYQuROJ9GytNIAT5Ih/Figma-Design?node-id=5-83
- **用途**: 训练界面(WorkoutScreen)的设计参考
- **应用**: 用于紧凑型布局设计，包括：
  - 顶部导航区域设计
  - 信息卡片布局结构
  - 底部操作按钮设计
  - 颜色搭配和视觉层次

### 2. main-screen-design.png
- **来源**: https://www.figma.com/make/lCPg8s7WnYrDk4kXvw3kSk/健身应用主界面设计?node-id=0-1
- **用途**: 主界面(MainScreen)的设计参考
- **应用**: 用于主界面布局和组件设计

## 🎨 设计规范

基于这些设计素材实现的UI组件：
- **CompactExerciseInfoCard**: 基于workout-screen-design.png的模块化布局
- **颜色系统**: 橙色(时间)、蓝色(组数)、绿色(次数)、紫色(重量)
- **间距规范**: 16pt标准间距，12pt紧凑间距
- **圆角设计**: 16pt大圆角，12pt中圆角，8pt小圆角

## 📝 使用说明

开发过程中参考这些设计素材时：
1. 保持颜色一致性和视觉层次
2. 遵循模块化设计原则
3. 注意间距和对齐规范
4. 确保在不同屏幕尺寸下的适配性
