## 🏗️ 技术架构概览

### 核心技术栈
- **SwiftUI**: 现代化声明式UI框架
- **Combine**: 响应式编程框架
- **MVVM**: Model-View-ViewModel架构模式
- **iOS 15.0+**: 最低支持版本

### 架构层次
```
┌─────────────────────────────────┐
│         View Layer             │  SwiftUI Views
├─────────────────────────────────┤
│       ViewModel Layer          │  ObservableObjects
├─────────────────────────────────┤
│       Service Layer            │  Business Logic
├─────────────────────────────────┤
│        Model Layer             │  Data Models
└─────────────────────────────────┘
```

### 主要组件
- **NavigationManager**: 全局导航和状态管理
- **WorkoutViewModel**: 训练会话管理
- **ExternalTrainingPlanService**: 外部数据处理
- **MockDataProvider**: 示例数据和测试支持

## 🚀 快速开始

### 1. 环境准备
```bash
# 检查系统要求
macOS 14.0+
Xcode 15.0+
iOS 15.0+

# 克隆项目
git clone <repository-url>
cd Fit

# 打开项目
open Fit.xcodeproj
```

### 2. 运行项目
1. 在 Xcode 中选择目标设备
2. 点击运行按钮 (⌘+R)
3. 应用将在设备上启动

### 3. 核心功能测试
