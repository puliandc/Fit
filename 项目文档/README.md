# Fit iOS 健身应用项目文档

## 概述

Fit 是一个专为 iOS 设计的智能健身助手应用，采用现代 SwiftUI 框架开发。应用提供训练计划管理、实时训练指导、进度跟踪等核心功能，帮助用户科学高效地进行健身训练。

## 核心功能

### 🏋️ 训练管理
- **训练计划读取**: 支持从 iPhone 下载文件夹读取 JSON 格式的训练计划
- **实时训练指导**: 提供组数、次数、重量、休息时间的完整指导
- **训练进度跟踪**: 实时显示训练完成进度和剩余时间

### 📱 现代化界面
- **Material Design**: 采用现代化的毛玻璃效果和渐变设计
- **流畅动画**: 丰富的转场动画和微交互效果
- **响应式布局**: 适配不同屏幕尺寸的 iPhone 设备

### 🔧 技术特性
- **MVVM 架构**: 采用 Model-View-ViewModel 设计模式
- **数据持久化**: 支持 JSON 格式的训练计划导入和解析
- **状态管理**: 使用 Combine 框架进行响应式状态管理

## 快速开始

### 环境要求
- Xcode 15.0+
- iOS 15.0+
- Swift 5.9+

### 安装和运行
1. 克隆项目到本地
2. 打开 `Fit.xcodeproj`
3. 选择目标设备或模拟器
4. 点击运行按钮

详细说明请参考 [快速上手指南](开发指南/快速上手.md)
