# Fit iOS 应用快速上手指南

## 概述

本指南将帮助新开发者快速了解 Fit iOS 健身应用的项目结构、开发环境设置和基本开发流程。

## 项目简介

Fit 是一个基于 SwiftUI 开发的现代 iOS 健身应用，主要功能包括：
- 训练计划导入和管理
- 实时训练指导和计时
- 训练进度跟踪
- 现代化的用户界面

## 技术栈

### 核心技术
- **SwiftUI**: 用户界面框架
- **Combine**: 响应式编程框架
- **iOS 15.0+**: 最低支持版本
- **Xcode 15.0+**: 开发工具要求

### 架构模式
- **MVVM**: Model-View-ViewModel 架构
- **ObservableObject**: 状态管理
- **@Published**: 响应式数据绑定

## 开发环境设置

### 1. 系统要求
- macOS 14.0 (Sonoma) 或更高版本
- Xcode 15.0 或更高版本
- iOS 15.0+ 设备或模拟器

### 2. 项目克隆和设置

```bash
# 克隆项目
git clone <repository-url>
cd Fit

# 打开项目
open Fit.xcodeproj
```

### 3. 项目配置

在 Xcode 中进行以下配置：

#### 签名和证书
1. 选择项目根目录
2. 在 "Signing & Capabilities" 标签页中：
   - 设置 Team（开发者账号）
   - 设置 Bundle Identifier
   - 选择自动签名

#### 目标设备
1. 选择目标设备或模拟器
2. 推荐使用 iPhone 15 Pro 模拟器进行开发

### 4. 依赖管理

项目目前使用 iOS 内置框架，无需额外的第三方依赖。

## 基本开发流程

### 1. 运行项目

1. 在 Xcode 中选择目标设备或模拟器
2. 点击运行按钮 (⌘+R)
3. 应用将在选定的设备上启动

### 2. 调试模式

应用包含调试模式，可用于开发测试：

启用调试模式：

2. 将文件放入iPhone的下载文件夹

4. 选择文件并验证解析结果

1. 确保有训练计划加载
2. 点击"开始训练"按钮
3. 测试训练过程中的各种操作：
   - 开始/暂停练习
   - 完成组数
   - 跳过练习
   - 退出训练

## 核心概念理解

### 1. MVVM 架构

#### Model (模型层)
- 负责数据定义和业务逻辑
- 主要类：`Exercise`、`WorkoutPlan`、`TrainingPlan`

```swift
struct Exercise: Identifiable, Codable, Hashable {
    let id: UUID
    let name: String
    let category: ExerciseCategory
    let muscleGroups: [MuscleGroup]
    // ...
}
```

#### View (视图层)
- 负责用户界面展示
- 使用SwiftUI声明式语法
- 响应ViewModel状态变化

```swift
struct MainScreen: View {
    @EnvironmentObject var navigationManager: NavigationManager

    var body: some View {
        // UI 组件定义
    }
}
```

#### ViewModel (视图模型层)
- 连接Model和View的桥梁
- 管理应用状态和业务逻辑
- 使用`ObservableObject`和`@Published`

```swift
class WorkoutViewModel: ObservableObject {
    @Published var currentExerciseIndex: Int = 0
    @Published var isExerciseActive: Bool = false

    func startExercise() {
        // 业务逻辑实现
    }
}
```

### 2. 响应式编程

使用Combine框架进行响应式编程：

```swift
// 在NavigationManager中
@Published var currentScreen: AppScreen = .main

// 在View中自动响应
@EnvironmentObject var navigationManager: NavigationManager

var body: some View {
    switch navigationManager.currentScreen {
    case .main:
        MainScreen()
    // ...
    }
}
```

### 3. 状态管理

应用采用集中式状态管理：

```swift
// 全局导航状态
class NavigationManager: ObservableObject {
    @Published var currentScreen: AppScreen = .main
    @Published var presentedDialog: DialogType?
    @Published var currentWorkoutViewModel: WorkoutViewModel?
}

// 训练状态
class WorkoutViewModel: ObservableObject {
    @Published var currentExerciseIndex: Int = 0
    @Published var isExerciseActive: Bool = false
    @Published var completedSets: [CompletedSet] = []
}
```

## 代码规范

### 1. 命名规范
- **类名**: 大驼峰命名法 (PascalCase)
- **方法和变量**: 小驼峰命名法 (camelCase)
- **常量**: 全大写下划线分隔 (UPPER_SNAKE_CASE)

### 2. 文件组织
- 每个文件只包含一个主要类或结构体
- 使用MARK注释组织代码段
- 保持文件长度合理（通常不超过500行）

### 3. 注释规范
```swift
//
//  FileName.swift
//  Fit
//
//  Created by 作者名 on 创建日期.
//

import SwiftUI

// MARK: - 类/结构体说明
/// 类或结构体的主要功能描述
class ClassName {
    // MARK: - Properties
    /// 属性说明
    @Published var property: Type

    // MARK: - Methods
    /// 方法说明
    /// - Parameter parameter: 参数说明
    /// - Returns: 返回值说明
    func methodName(parameter: Type) -> ReturnType {
        // 实现
    }
}
```
