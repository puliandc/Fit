# Fit iOS 应用开发环境配置指南

## 概述

本文档详细介绍如何配置 Fit iOS 应用的开发环境，包括系统要求、工具安装、项目设置和开发配置。

## 系统要求

### 硬件要求
- **Mac电脑**: MacBook Pro、MacBook Air、iMac、Mac mini 或 Mac Pro
- **内存**: 最少 8GB RAM，推荐 16GB 或更多
- **存储**: 至少 20GB 可用磁盘空间用于 Xcode 和工具
- **处理器**: Apple Silicon (M1/M2/M3) 或 Intel 处理器

### 软件要求
- **操作系统**: macOS 14.0 (Sonoma) 或更高版本
- **Xcode**: 15.0 或更高版本
- **iOS SDK**: iOS 15.0 SDK 或更高版本
- **Git**: 用于版本控制（推荐安装）

## Xcode 安装和配置

### 1. 安装 Xcode

#### 从 App Store 安装（推荐）
1. 打开 App Store
2. 搜索 "Xcode"
3. 点击"获取"或安装按钮
4. 等待下载和安装完成

#### 从 Apple Developer 网站下载
1. 访问 [Apple Developer](https://developer.apple.com/xcode/)
2. 登录 Apple Developer 账号
3. 下载 Xcode 15.0 或更高版本
4. 双击下载的 .xip 文件进行解压
5. 将 Xcode.app 移动到 Applications 文件夹

### 2. Xcode 初始配置

#### 命令行工具安装
```bash
# 安装 Xcode 命令行工具
xcode-select --install

# 设置开发者目录（如果需要）
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

#### 同意许可协议
```bash
# 同意 Xcode 许可协议
sudo xcodebuild -license accept
```

### 3. 验证安装

```bash
# 检查 Xcode 版本
xcodebuild -version

# 检查 SDK 版本
xcodebuild -showsdks

# 检查开发工具
xcode-select -p
```

## 开发账号设置

### 1. Apple Developer 账号

#### 免费开发者账号
- 可以在真机上测试应用
- 应用有效期 7 天
- 每个设备最多 3 个应用

#### 付费开发者账号（$99/年）
- 应用有效期 1 年
- 可发布到 App Store
- 支持推送通知等高级功能
- 可使用 TestFlight 进行 Beta 测试

### 2. 在 Xcode 中配置账号

#### 添加开发者账号
1. 打开 Xcode
2. 选择 "Xcode" → "Settings" (或 "Preferences")
3. 点击 "Accounts" 标签页
4. 点击左下角的 "+" 按钮
5. 选择 "Apple ID"
6. 输入 Apple ID 和密码
7. 选择账号类型（个人或组织）

#### 下载证书和配置文件
1. 在账号列表中选择你的 Apple ID
2. 点击 "Download Manual Profiles"
3. 等待证书和配置文件下载完成

### 3. 项目签名配置

#### 自动签名（推荐）
1. 在 Xcode 中打开项目
2. 选择项目根目录
3. 在 "Signing & Capabilities" 标签页中：
   - ✅ 勾选 "Automatically manage signing"
   - 设置 "Team" 为你的开发者账号
   - 修改 "Bundle Identifier" 为唯一标识符

#### 手动签名
1. 在 Apple Developer 网站创建 App ID
2. 创建开发和发布证书
3. 创建配置文件
4. 在 Xcode 中手动配置

## Git 版本控制配置

### 1. Git 安装

#### macOS 内置 Git
```bash
# 检查 Git 版本（macOS 通常预装）
git --version

# 如果没有安装，使用 Homebrew 安装
brew install git
```

### 2. Git 配置

#### 基本配置
```bash
# 配置用户名和邮箱
git config --global user.name "你的姓名"
git config --global user.email "your.email@example.com"

# 设置默认分支名
git config --global init.defaultBranch main

# 配置编辑器
git config --global core.editor "code --wait"  # 使用 VS Code
```

#### 配置 SSH 密钥（推荐）
```bash
# 生成 SSH 密钥
ssh-keygen -t ed25519 -C "your.email@example.com"

# 启动 ssh-agent
eval "$(ssh-agent -s)"

# 添加密钥到 ssh-agent
ssh-add ~/.ssh/id_ed25519

# 复制公钥到剪贴板
pbcopy < ~/.ssh/id_ed25519.pub

# 将公钥添加到 GitHub/GitLab 等平台
```

### 3. 克隆项目

```bash
# 克隆项目仓库
git clone <repository-url>

# 进入项目目录
cd Fit

# 查看项目状态
git status
```

## 模拟器和设备配置

### 1. iOS 模拟器

#### 查看可用模拟器
```bash
# 列出所有可用模拟器
xcrun simctl list devices

# 仅列出可用设备
xcrun simctl list devices available
```

#### 创建新模拟器
1. 打开 Xcode
2. 选择 "Window" → "Devices and Simulators"
3. 点击 "+" 按钮
4. 选择设备类型和系统版本
5. 点击 "Create"

#### 模拟器管理
```bash
# 启动特定模拟器
xcrun simctl boot "iPhone 15 Pro"

# 关闭模拟器
xcrun simctl shutdown "iPhone 15 Pro"

# 删除模拟器
xcrun simctl delete "iPhone 15 Pro"
```

### 2. 真机调试

#### 连接设备
1. 使用 USB 线连接 iOS 设备到 Mac
2. 在设备上信任此电脑（首次连接时）
3. 在 Xcode 中选择设备作为运行目标

#### 设备配置检查
1. 在 Xcode 中选择 "Window" → "Devices and Simulators"
2. 选择你的设备
3. 检查以下信息：
   - **Identifier**: 设备唯一标识符
   - **Version**: iOS 版本是否兼容
   - **Capacity**: 存储空间
   - **Signing**: 证书是否正确

## 项目配置

### 1. 打开项目

```bash
# 使用命令行打开项目
open Fit.xcodeproj

# 或者在 Xcode 中打开
# File → Open → 选择 Fit.xcodeproj
```

### 2. 项目设置检查

#### General 设置
1. 选择项目根目录
2. 在 "General" 标签页中检查：
   - **Display Name**: 应用显示名称
   - **Bundle Identifier**: 唯一标识符
   - **Version**: 版本号
   - **Build**: 构建号
   - **Deployment Target**: iOS 15.0+

#### Signing & Capabilities
1. 检查签名配置
2. 确认 Team 设置正确
3. 检查必要的 Capabilities

#### Build Settings
1. 检查编译器设置
2. 确认 Swift 版本
3. 检查其他构建设置

## 故障排除

### 1. 常见问题

#### Xcode 无法启动
```bash
# 清理 Xcode 缓存
rm -rf ~/Library/Developer/Xcode/DerivedData
rm -rf ~/Library/Caches/com.apple.dt.Xcode

# 重启 Xcode
```

#### 证书问题
1. 检查开发者账号状态
2. 重新下载证书
3. 清理并重新生成配置文件

#### 模拟器问题
```bash
# 重置模拟器
xcrun simctl erase all

# 重启模拟器服务
sudo xcrun simctl shutdown all
sudo launchctl unload /Library/LaunchDaemons/com.apple.appleseed.seedService.plist
```

### 2. 性能优化

#### Xcode 性能

- 使用 SSD 存储

#### 编译优化
