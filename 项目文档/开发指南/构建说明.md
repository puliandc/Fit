# Fit iOS 应用构建说明

## 概述

本文档详细说明如何构建 Fit iOS 应用，包括开发构建、发布构建、测试构建等不同场景的配置和流程。

## 构建类型

### 1. 开发构建 (Development Build)
- **目标**: 开发和调试
- **配置**: Debug
- **目标设备**: 模拟器和开发设备
- **特点**: 包含调试信息，无代码优化

### 2. 测试构建 (Testing Build)
- **目标**: 内部测试和 QA
- **配置**: Release 或 Ad-hoc
- **目标设备**: 测试设备
- **特点**: 接近生产环境，支持分发给测试人员

### 3. 发布构建 (Release Build)
- **目标**: App Store 发布
- **配置**: Release
- **目标设备**: 生产环境
- **特点**: 完全优化，通过 Apple 审核

## Xcode 构建配置

### 1. 构建设置概览

#### 基本构建设置
```
项目: Fit
Target: Fit
Configuration: Debug/Release
SDK: iOS
Deployment Target: iOS 15.0
```

#### 重要构建设置

**编译器设置**
- **Swift Language Version**: Swift 5.9
- **Objective-C Language**: Default
- **C++ Language**: Default
- **C Language**: Default

**代码生成**
- **Optimization Level**: Debug: [-O0], Release: [-O3]
- **Debug Information Format**: DWARF with dSYM File
- **Enable Bitcode**: No (iOS 15.0+ 不再需要)

**链接设置**
- **Other Linker Flags**: 无特殊要求
- **Enable Objective-C Exceptions**: Yes
- **Enable C++ Exceptions**: Yes

### 2. 配置管理

#### Debug 配置
```swift
// Build Settings → Debug Configuration
SWIFT_ACTIVE_COMPILATION_CONDITIONS = DEBUG
ENABLE_TESTABILITY = YES
GCC_OPTIMIZATION_LEVEL = 0
SWIFT_OPTIMIZATION_LEVEL = "-Onone"
VALIDATE_PRODUCT = NO
```

#### Release 配置
```swift
// Build Settings → Release Configuration
SWIFT_ACTIVE_COMPILATION_CONDITIONS = ""
ENABLE_TESTABILITY = NO
GCC_OPTIMIZATION_LEVEL = 3
SWIFT_OPTIMIZATION_LEVEL = "-O"
VALIDATE_PRODUCT = YES
```

## 构建步骤

### 1. 开发构建

#### 命令行构建
```bash
# 清理构建目录
xcodebuild clean -project Fit.xcodeproj -scheme Fit -configuration Debug

# 构建 Debug 版本
xcodebuild build -project Fit.xcodeproj -scheme Fit -configuration Debug -destination "platform=iOS Simulator,name=iPhone 15 Pro"

# 运行在模拟器
xcodebuild test -project Fit.xcodeproj -scheme Fit -destination "platform=iOS Simulator,name=iPhone 15 Pro"
```

#### Xcode 界面构建
1. 打开 Xcode 项目
2. 选择目标设备或模拟器
3. 选择 scheme: Fit → My Mac (用于模拟器) 或 iOS Device
4. 点击 Product → Build (⌘+B)
5. 点击 Product → Run (⌘+R)

### 2. 测试构建

#### Ad-hoc 构建
```bash
# 构建 Ad-hoc 版本
xcodebuild archive \
  -project Fit.xcodeproj \
  -scheme Fit \
  -configuration Release \
  -archivePath ./build/Fit.xcarchive \
  -destination generic/platform=iOS \
  PROVISIONING_PROFILE_SPECIFIER="com.yourteam.fit" \
  CODE_SIGN_IDENTITY="iPhone Distribution"

# 导出 IPA
xcodebuild -exportArchive \
  -archivePath ./build/Fit.xcarchive \
  -exportPath ./build \
  -exportOptionsPlist ExportOptions.plist
```

#### ExportOptions.plist 配置
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>method</key>
    <string>ad-hoc</string>
    <key>teamID</key>
    <string>YOUR_TEAM_ID</string>
    <key>uploadBitcode</key>
    <false/>
    <key>compileBitcode</key>
    <false/>
    <key>provisioningProfiles</key>
    <dict>
        <key>com.yourcompany.fit</key>
        <string>your-provisioning-profile</string>
    </dict>
</dict>
</plist>
```

## 自动化构建脚本

### 1. 开发构建脚本

```bash
#!/bin/bash
# build_dev.sh - 开发构建脚本

set -e

echo "🚀 开始开发构建..."

# 项目配置
PROJECT_NAME="Fit"
SCHEME_NAME="Fit"
CONFIGURATION="Debug"
DESTINATION="platform=iOS Simulator,name=iPhone 15 Pro"

# 清理构建目录
echo "🧹 清理构建目录..."
xcodebuild clean -project ${PROJECT_NAME}.xcodeproj -scheme ${SCHEME_NAME} -configuration ${CONFIGURATION}

# 构建项目
echo "🔨 构建项目..."
xcodebuild build \
  -project ${PROJECT_NAME}.xcodeproj \
  -scheme ${SCHEME_NAME} \
  -configuration ${CONFIGURATION} \
  -destination "${DESTINATION}" \
  | xcpretty

# 运行测试
echo "🧪 运行测试..."
xcodebuild test \
  -project ${PROJECT_NAME}.xcodeproj \
  -scheme ${SCHEME_NAME} \
  -destination "${DESTINATION}" \
  | xcpretty

echo "✅ 开发构建完成!"
```

### 2. 发布构建脚本

```bash
#!/bin/bash
# build_release.sh - 发布构建脚本

set -e

echo "🚀 开始发布构建..."

# 项目配置
PROJECT_NAME="Fit"
SCHEME_NAME="Fit"
CONFIGURATION="Release"
TEAM_ID="YOUR_TEAM_ID"
BUNDLE_ID="com.yourcompany.fit"

# 构建路径
BUILD_DIR="./build"
ARCHIVE_PATH="${BUILD_DIR}/Fit.xcarchive"
EXPORT_PATH="${BUILD_DIR}/release"

# 清理构建目录
echo "🧹 清理构建目录..."
rm -rf ${BUILD_DIR}
mkdir -p ${BUILD_DIR}

# Archive 项目
echo "📦 创建 Archive..."
xcodebuild archive \
  -project ${PROJECT_NAME}.xcodeproj \
  -scheme ${SCHEME_NAME} \
  -configuration ${CONFIGURATION} \
  -archivePath ${ARCHIVE_PATH} \
  -destination generic/platform=iOS \
  PROVISIONING_PROFILE_SPECIFIER="${BUNDLE_ID}" \
  CODE_SIGN_IDENTITY="iPhone Distribution" \
  | xcpretty

# 导出 IPA
echo "📤 导出 IPA..."
xcodebuild -exportArchive \
  -archivePath ${ARCHIVE_PATH} \
  -exportPath ${EXPORT_PATH} \
  -exportOptionsPlist AppStoreExportOptions.plist \
  | xcpretty

echo "✅ 发布构建完成!"
echo "📱 IPA 文件位置: ${EXPORT_PATH}"
```

## 持续集成配置

### 1. GitHub Actions 配置

```yaml
# .github/workflows/ios.yml
name: iOS CI

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: macos-latest

    steps:
    - uses: actions/checkout@v3

    - name: Select Xcode
      run: sudo xcode-select -switch /Applications/Xcode.app/Contents/Developer

    - name: Cache derived data
      uses: actions/cache@v3
      with:
        path: ~/Library/Developer/Xcode/DerivedData
        key: ${{ runner.os }}-derived-data-${{ hashFiles('**/*.swift') }}
        restore-keys: |
          ${{ runner.os }}-derived-data-

    - name: Build and Test
      run: |
        xcodebuild clean build test \
          -project Fit.xcodeproj \
          -scheme Fit \
          -destination 'platform=iOS Simulator,name=iPhone 15 Pro' \
          CODE_SIGN_IDENTITY="" \
          CODE_SIGNING_REQUIRED=NO
```

### 2. Fastlane 配置

```ruby
# Fastfile
platform :ios do
  before_all do
    setup_circle_ci if ENV['CI']
  end

  desc "运行测试"
  lane :test do
    scan(
      project: "Fit.xcodeproj",
      scheme: "Fit",
      device: "iPhone 15 Pro",
      clean: true
    )
  end

  desc "构建 Ad-hoc 版本"
  lane :build_adhoc do
    build_app(
      project: "Fit.xcodeproj",
      scheme: "Fit",
      configuration: "Release",
      export_method: "ad-hoc",
      output_directory: "./build",
      output_name: "Fit.adhoc.ipa"
    )
  end

  desc "发布到 App Store"
  lane :release do
    build_app(
      project: "Fit.xcodeproj",
      scheme: "Fit",
      configuration: "Release",
      export_method: "app-store"
    )

    upload_to_app_store(
      skip_screenshots: true,
      skip_metadata: true,
      force: true
    )
  end
end
```
