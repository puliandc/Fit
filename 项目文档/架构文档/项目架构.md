# Fit iOS 应用架构文档

## 整体架构概述

Fit 应用采用 **MVVM (Model-View-ViewModel)** 架构模式，结合现代 SwiftUI 框架的响应式特性，构建了一个可扩展、可维护的 iOS 健身应用。

## 核心组件详解

### 1. 应用入口层 (App Layer)

#### FitApp.swift
- **职责**: 应用程序入口点和环境对象管理
- **核心功能**:
  - 初始化 NavigationManager
  - 设置应用级别的环境对象
  - 配置主窗口

```swift
@main
struct FitApp: App {
    @StateObject private var navigationManager = NavigationManager()

    var body: some Scene {
        WindowGroup {
            ContentView()
                .environmentObject(navigationManager)
        }
    }
}
```

### 2. 视图层 (View Layer)

#### ContentView.swift
- **职责**: 主要视图容器和导航控制器
- **核心功能**:
  - 屏幕切换逻辑管理
  - 对话框显示控制
  - 全局转场动画

#### MainScreen.swift
- **职责**: 主界面展示和用户交互
- **核心功能**:
  - 训练计划状态显示
  - 文件选择和读取
  - 调试模式功能
- **设计特色**: 现代化毛玻璃效果和流畅动画

#### WorkoutScreen.swift
- **职责**: 训练执行界面
- **核心功能**:
  - 实时训练指导
  - 计时器管理
  - 进度显示和状态更新

### 3. 视图模型层 (ViewModel Layer)

#### NavigationManager.swift
- **职责**: 全局导航状态管理
- **核心功能**:
  - 屏幕导航栈管理
  - 对话框状态控制
  - WorkoutViewModel 生命周期管理
- **设计模式**: ObservableObject + @Published

```swift
class NavigationManager: ObservableObject {
    @Published var currentScreen: AppScreen = .main
    @Published var navigationStack: [AppScreen] = []
    @Published var presentedDialog: DialogType?
    @Published var currentWorkoutViewModel: WorkoutViewModel?
}
```

#### WorkoutViewModel.swift
- **职责**: 训练会话状态管理
- **核心功能**:
  - 练习进度跟踪
  - 计时器管理
  - 训练数据记录
- **状态管理**: Combine 框架响应式更新

### 4. 服务层 (Service Layer)

#### ExternalTrainingPlanService.swift
- **职责**: 外部训练计划处理
- **核心功能**:
  - JSON 文件解析
  - 数据验证和转换
  - 错误处理和恢复

#### JSONWorkoutParser.swift
- **职责**: JSON 数据解析器
- **核心功能**:
  - 训练计划数据解析
  - 数据模型转换
  - 格式验证

#### FileSecurityValidator.swift
- **职责**: 文件安全性验证
- **核心功能**:
  - 文件格式检查
  - 安全性验证
  - 权限确认

### 5. 数据模型层 (Model Layer)

#### MockData.swift
- **职责**: 示例数据提供和数据模型定义
- **核心模型**:
  - `Exercise`: 练习项目数据模型
  - `ExerciseSet`: 练习组配置模型
  - `WorkoutPlan`: 训练计划模型
  - `WorkoutSession`: 训练会话模型

#### WorkoutDataModels.swift
- **职责**: 简化的训练数据模型
- **核心模型**:
  - `TrainingPlan`: 简化训练计划
  - `TrainingExercise`: 训练练习
  - `TrainingSet`: 训练组
  - `TrainingSession`: 训练会话

#### WorkoutBusinessLogic.swift
- **职责**: 业务逻辑处理
- **核心功能**:
  - 进度计算逻辑
  - 训练会话管理
  - 数据验证

## 数据流架构

### 响应式数据流
```
User Action → View → ViewModel → Service → Model
     ↑                                                    ↓
UI Update ← @Published ← Combine ← Business Logic ← Data
```

### 状态管理模式
- **单向数据流**: 确保数据流向的可预测性
- **响应式更新**: 使用 @Published 和 Combine 框架
- **状态隔离**: 不同功能模块的状态独立管理

## 关键设计决策

### 1. SwiftUI 原生开发
- **优势**: 性能优化、声明式语法、现代化 API
- **考虑**: iOS 15.0+ 兼容性要求

### 2. MVVM 架构模式
- **优势**: 关注点分离、可测试性、可维护性
- **实现**: ObservableObject + @Published 响应式绑定

### 3. 文件导入机制
- **设计**: 支持用户自定义训练计划
- **实现**: JSON 格式解析 + 安全性验证

### 4. 计时器管理
- **挑战**: 多个计时器协调、生命周期管理
- **解决方案**: 统一的计时器管理器 + 状态同步

## 性能优化策略

### 1. 视图优化
- **Lazy Loading**: 按需加载视图组件
- **View Reuse**: 视图复用和缓存
- **Animation Performance**: 优化动画性能

### 2. 内存管理
- **Weak References**: 避免循环引用
- **Object Lifecycle**: 合理的对象生命周期管理
- **Timer Cleanup**: 及时清理计时器资源

### 3. 数据处理
- **Async Processing**: 异步数据处理
- **Data Caching**: 数据缓存机制
- **Incremental Updates**: 增量数据更新

## 扩展性考虑

### 1. 模块化设计
- **Component Separation**: 组件功能边界清晰
- **Interface Design**: 良好的接口设计
- **Dependency Injection**: 依赖注入支持

### 2. 功能扩展点
- **New Exercise Types**: 支持新的练习类型
- **Additional Data Sources**: 支持更多数据源
- **Custom Workflows**: 支持自定义训练流程

### 3. 平台适配
- **iPad Support**: iPad 界面适配
- **Watch Integration**: Apple Watch 集成准备
- **Cloud Sync**: 云端数据同步支持
