# Fit iOS 应用核心类 API 文档

## 概述

本文档详细说明 Fit iOS 应用的核心类和接口，包括其功能、方法、属性和使用示例。

## 核心类列表

### 1. FitApp
**文件位置**: `Fit/FitApp.swift`
**职责**: 应用程序入口点和全局环境对象管理

#### 属性
- `@StateObject private var navigationManager: NavigationManager` - 导航管理器实例

#### 方法
- `var body: some Scene` - 应用程序主体，设置主窗口和环境对象

#### 使用示例
```swift
@main
struct FitApp: App {
    @StateObject private var navigationManager = NavigationManager()

    var body: some Scene {
        WindowGroup {
            ContentView()
                .environmentObject(navigationManager)
        }
    }
}
```

### 2. NavigationManager
**文件位置**: `Fit/NavigationManager.swift`
**职责**: 全局导航状态管理，包括屏幕切换、对话框管理和训练ViewModel生命周期

#### 属性
```swift
@Published var currentScreen: AppScreen           // 当前屏幕
@Published var navigationStack: [AppScreen]       // 导航栈
@Published var presentedDialog: DialogType?      // 当前显示的对话框
@Published var currentWorkoutViewModel: WorkoutViewModel? // 当前训练ViewModel
```

#### 导航方法
```swift
// 基本导航
func navigate(to screen: AppScreen)              // 导航到指定屏幕
func goBack()                                   // 返回上一屏幕
func popToRoot()                                // 返回根屏幕
func resetToMain()                              // 重置到主屏幕

// 训练导航
func startWorkout(_ plan: WorkoutPlan)          // 开始训练
func pauseWorkout()                             // 暂停训练
func resumeWorkout()                            // 恢复训练
func completeWorkout()                          // 完成训练
func quitWorkout()                              // 退出训练

// 对话框管理
func presentDialog(_ dialog: DialogType)        // 显示对话框
func dismissDialog()                            // 关闭对话框
```

#### 工具方法
```swift
func canGoBack() -> Bool                        // 检查是否可以返回
func getNavigationDepth() -> Int               // 获取导航深度
```

#### 使用示例
```swift
// 在 View 中使用
struct MainScreen: View {
    @EnvironmentObject var navigationManager: NavigationManager

    var body: some View {
        VStack {
            Button("开始训练") {
                let workoutPlan = MockDataProvider.previewWorkout
                navigationManager.startWorkout(workoutPlan)
            }

            Button("设置") {
                navigationManager.navigate(to: .settings)
            }
        }
    }
}
```

### 3. WorkoutViewModel
**文件位置**: `Fit/ViewModels/WorkoutViewModel.swift`
**职责**: 训练会话状态管理，包括练习进度、计时器和数据记录

#### 属性
```swift
@Published var currentExerciseIndex: Int = 0       // 当前练习索引
@Published var currentSet: Int = 1                  // 当前组数
@Published var exerciseElapsedTime: Int = 0        // 练习耗时
@Published var isExerciseActive: Bool = false      // 练习是否活跃
@Published var isResting: Bool = false              // 是否在休息
@Published var timeLeft: Int = 0                    // 剩余休息时间
@Published var completedSets: [CompletedSet] = []   // 已完成组数

let workoutPlan: WorkoutPlan                       // 训练计划
```

#### 计算属性
```swift
var currentExercise: Exercise                     // 当前练习
var currentExerciseSet: ExerciseSet               // 当前练习组
var progress: Double                              // 训练进度 (0.0-1.0)
var isWorkoutComplete: Bool                       // 训练是否完成
var totalWorkoutTime: Int                         // 总训练时间
```

#### 练习管理方法
```swift
func startExercise()                              // 开始练习
func pauseExercise()                               // 暂停练习
func toggleExercise()                              // 切换练习状态
func completeExercise()                            // 完成练习（触发参数编辑）
func completeExerciseWith(actualReps: Int, actualWeight: Double) // 完成指定参数的练习
```

#### 导航方法
```swift
func moveToNextExercise()                         // 移动到下一个练习
func skipCurrentExerciseCompletely()             // 跳过当前练习的所有组
func skipAllRemainingExercises()                 // 跳过所有剩余练习
```

#### 休息管理方法
```swift
func startRest()                                  // 开始休息
func skipRest()                                   // 跳过休息
```

#### 工具方法
```swift

func getCompletedSetsCount(for exercise: Exercise) -> Int     // 获取已完成组数
func getRemainingSetsCount(for exercise: Exercise) -> Int     // 获取剩余组数
```

#### 使用示例

### 4. ExternalTrainingPlanService
**文件位置**: `Fit/Services/ExternalTrainingPlanService.swift`
**职责**: 外部训练计划处理，包括文件读取、JSON解析和数据验证

#### 属性
```swift
@Published var currentWorkoutPlan: WorkoutPlan? // 当前训练计划
@Published var errorMessage: String?              // 错误信息
private let parser: JSONWorkoutParser           // JSON解析器
private let validator: FileSecurityValidator     // 文件安全验证器
```

#### 主要方法
```swift
func loadWorkoutPlan(from url: URL) async       // 从URL加载训练计划
func clearError()                                // 清除错误信息
```

#### 使用示例
```swift
// 在 View 中使用
struct MainScreen: View {
    @StateObject private var externalService = ExternalTrainingPlanService()

    var body: some View {
        VStack {
            if let workoutPlan = externalService.currentWorkoutPlan {
                Text("已加载: \(workoutPlan.name)")
                Button("开始训练") {
                    navigationManager.startWorkout(workoutPlan)
                }
            } else {
                Button("读取训练计划") {
                    // 选择文件并加载
                }
            }

            if let error = externalService.errorMessage {
                Text("错误: \(error)")
                    .foregroundColor(.red)
            }
        }
        .onAppear {
            // 可以在这里自动加载默认训练计划
        }
    }
}
```

```swift
// 数据验证错误
enum ValidationError: Error, LocalizedError {
    case invalidExerciseName(String)

// JSON 解析错误
enum JSONParsingError: Error, LocalizedError {

// 文件处理错误
enum FileError: Error, LocalizedError {
```

### 错误处理示例
```swift
func validateExercise(_ exercise: Exercise) throws {
    if exercise.name.isEmpty {
        throw ValidationError.invalidExerciseName("练习名称不能为空")
    }

    if exercise.instructions.isEmpty {
        throw ValidationError.invalidExerciseName("练习说明不能为空")
    }
}
```

## 使用建议

### 1. 状态管理
- 使用 `@EnvironmentObject` 传递全局状态
- 使用 `@StateObject` 管理局部状态
- 避免在 View 中直接修改 `@Published` 属性

### 2. 内存管理
- 在 ViewModel 的 `deinit` 中清理计时器
- 使用 `weak` 引用避免循环引用
- 及时释放不再使用的资源

### 3. 错误处理
- 使用 `try-catch` 处理异步操作
- 提供用户友好的错误信息
- 实现错误恢复机制

### 4. 测试支持
- 使用 MockDataProvider 提供测试数据
- 创建可预测的测试场景
- 验证状态转换的正确性
