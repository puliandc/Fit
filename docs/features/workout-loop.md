# 训练循环功能用户故事

//created by Jason Lu on 09:17:00 10/12/2025

## 📋 功能概述

训练循环是Fit应用的核心功能，允许用户记录每次训练的组数、重量和次数，并跟踪训练进度。

## 🎯 用户故事

### 主要用户故事

#### 故事1：开始新的训练
**作为** 健身爱好者
**我想要** 快速开始一个新的训练记录
**以便于** 记录今天的训练活动

**验收标准**：
- [ ] 用户可以在主界面看到"开始训练"按钮

## 📊 数据流设计

### 训练数据流程

```
开始训练
    ↓
创建Workout实例
    ↓
进入训练界面
    ↓
添加训练组数
    ↓
数据验证
    ↓
保存WorkoutSet
    ↓
更新统计显示
    ↓
完成训练
    ↓
保存完整Workout
    ↓
返回主界面
```

### 数据模型关系

```swift
Workout {
    id: UUID
    date: Date
    startTime: Date
    endTime: Date?
    sets: [WorkoutSet]
    notes: String?
}

WorkoutSet {
    id: UUID
    workoutId: UUID
    weight: Double
    reps: Int
    timestamp: Date
    notes: String?
}
```

## 🚫 错误处理场景

### 场景1：输入验证失败
**描述**：用户输入无效数据时的处理

**处理方式**：
- 实时显示错误提示
- 禁用保存按钮
- 提供修正建议

### 场景2：意外退出
**描述**：用户在训练过程中意外退出应用

**处理方式**：
- 自动保存训练进度
- 重新进入时恢复状态
- 提示用户继续训练

### 场景3：数据保存失败
**描述**：训练完成时数据保存失败

**处理方式**：
- 显示明确错误信息
- 提供重试选项
- 数据临时缓存

### 场景4：内存不足
**描述**：设备内存不足时的处理

**处理方式**：
- 优雅降级界面
- 清理非必要数据
- 提示用户重启应用
