## 2. 字段详细说明

### 2.1 JSON 字段处理状态

| 字段名           | 类型   | 代码处理状态 | 数据来源  | 必填 | 说明                         |
| ---------------- | ------ | ------------ | --------- | ---- | ---------------------------- |
| **顶层字段**     |        |              |           |      |                              |
| "训练计划名称"   | String | ✅ 实际解析  | 第 34 行  | ✅   | 训练计划的名称               |
| "练习项目"       | Array  | ✅ 实际解析  | 第 41 行  | ✅   | 包含多个练习项目的数组       |
| **练习项目字段** |        |              |           |      |                              |
| "练习名称"       | String | ✅ 实际解析  | 第 100 行 | ✅   | 具体动作的名称               |
| "组数设置"       | Array  | ✅ 实际解析  | 第 111 行 | ✅   | 该练习的组数配置数组         |
| **组数设置字段** |        |              |           |      |                              |
| "目标次数"       | Int    | ✅ 实际解析  | 第 165 行 | ✅   | 该组的目标重复次数           |
| "目标重量"       | Double | ✅ 实际解析  | 第 165 行 | ✅   | 该组的目标重量(kg)           |
| "休息时间"       | Int    | ✅ 实际解析  | 第 171 行 | ✅   | 组间休息时间(秒)，默认 90 秒 |
| "组数类型"       | String | ❌ 被忽略    | -         | ❌   | 沟通用字段，当前版本不处理   |

### 2.2 数据转换规则

#### 2.2.1 类型转换

- **"目标重量"**: JSON 中的数字会自动转换为 Double 类型
- **"目标次数"**: JSON 中的整数会转换为 Int 类型
- **"休息时间"**: JSON 中的整数会转换为 Int 类型，默认值为 90 秒

#### 2.2.2 数据类型转换

- **"目标重量"**: JSON 中的数字会自动转换为 Double 类型
- **"目标次数"**: JSON 中的整数会转换为 Int 类型
- **"休息时间"**: JSON 中的整数会转换为 Int 类型，默认值为 90 秒

#### 2.2.3 扁平化数据处理

解析器采用扁平化处理方式：

```
JSON结构: 训练计划 → 练习项目 → 组数设置
内存结构: WorkoutPlan → [ExerciseSet] (直接扁平化)
```

### 2.3 实际数据模型说明

#### 2.3.1 WorkoutPlan 结构 (代码实际创建)

```swift
struct WorkoutPlan: Identifiable, Codable, Hashable, Equatable {
    let id: UUID
    let name: String                    // 来自"训练计划名称"
    let duration: Int                    // 自动计算(分钟)
    let exercises: [ExerciseSet]         // 扁平化的训练组数组
}
```

#### 2.3.2 ExerciseSet 结构 (代码实际创建)

```swift
struct ExerciseSet: Identifiable, Codable, Hashable {
    let id: UUID                         // 自动生成
    let exercise: Exercise               // 智能推断创建
    let targetReps: Int                  // 来自"目标次数"
    let targetWeight: Double             // 来自"目标重量"
    let restTime: Int                    // 来自"休息时间"(默认90)
}
```

## 3. 功能限制和默认值说明

### 3.1 当前版本限制

#### ❌ **不支持的功能**

- **训练组类型处理**: "组数类型"字段被完全忽略
- **SetType 枚举**: 不支持热身组、正式组、超级组的区分
- **练习间休息时间**: 不支持"exerciseRestTime"概念
- **显示顺序**: 不支持"displayOrder"排序
- **UUID 支持**: 不支持外部提供的 ID

#### ✅ **支持的功能**

- **基础 JSON 解析**: 支持中文字段名解析
- **数据类型转换**: 自动转换 Int/Double 类型
- **默认值处理**: 自动应用默认休息时间(90 秒)

### 3.2 默认值规则

| 属性     | 默认值 | 应用场景                         |
| -------- | ------ | -------------------------------- |
| 休息时间 | 90 秒  | 当 JSON 中未提供"休息时间"字段时 |

### 3.3 错误处理机制

解析器使用以下错误类型：

```swift
enum JSONParseError: LocalizedError {
    case invalidFormat      // JSON格式无效
    case invalidStructure   // JSON数据结构不正确
    case missingPlanName    // 缺少"训练计划名称"字段
    case missingExercises   // 缺少"练习项目"字段
    case missingExerciseName(Int)    // 第N个练习缺少"练习名称"
    case missingSetConfig(String)    // 练习"XXX"缺少"组数设置"
}
```

### 4.3 AI 集成指导

#### ✅ **AI 创建 JSON 时的注意事项**

1. **必填字段**: 确保"训练计划名称"、"练习项目"、"练习名称"、"组数设置"、"目标次数"、"目标重量"都存在
2. **数据类型**: "目标次数"为整数，"目标重量"为数字
3. **字段命名**: 使用纯中文字段名，不要使用英文
4. **结构层级**: 严格按照"训练计划 → 练习项目 → 组数设置"的嵌套结构

#### ⚠️ **常见错误避免**

```json
// ❌ 错误：使用英文字段名
{
  "name": "训练计划",
  "exercises": [...]
}

// ❌ 错误：缺少必要字段
{
  "训练计划名称": "训练",
  "练习项目": [
    {
      "练习名称": "卧推"
      // 缺少"组数设置"
    }
  ]
}

// ✅ 正确：使用中文格式和完整字段
{
  "训练计划名称": "训练计划",
  "练习项目": [
    {
      "练习名称": "卧推",
      "组数设置": [
        {
          "目标次数": 10,
          "目标重量": 50
        }
      ]
    }
  ]
}
```
